# Вимоги до ІС "Готель"

## Функціональні вимоги (FR)
| ID | Опис | Пріоритет | Критерій прийняття |
|----|------|-----------|--------------------|
| FR-01 | Пошук вільних номерів за датами | Високий | Система виводить список доступних номерів |
| FR-02 | Бронювання номера гостем | Високий | Створюється запис бронювання зі статусом "Pending" |
| FR-03 | Онлайн-оплата бронювання | Високий | Статус змінюється на "Paid" після успішної транзакції |
| FR-04 | Реєстрація заїзду (Check-in) адміністратором | Середній | Зміна статусу номера на "Occupied" |
| FR-05 | Скасування бронювання | Середній | Номер знову стає доступним для бронювання |
| FR-06 | Генерація звітів про завантаженість готелю | Низький | Формування PDF/XLSX звітів за період |

## Нефункціональні вимоги (NFR)
| ID | Категорія | Опис |
|----|-----------|------|
| NFR-01 | Продуктивність | Час відгуку на пошук номерів не перевищує 1.5 сек |
| NFR-02 | Безпека | Паролі та персональні дані користувачів шифруються (BCrypt / AES) |
| NFR-03 | Доступність | Система доступна 99.9% часу (24/7) |
