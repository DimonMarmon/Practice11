# Глосарій термінів ІС "Готель"

- **Гілка (Branch)** — Паралельна версія репозиторію в Git.
- **Check-in (Заїзд)** — Процес офіційної реєстрації та поселення гостя в номер.
- **Check-out (Виїзд)** — Процес звільнення номера, розрахунку та здачі ключів.
- **Overbooking (Перебронювання)** — Ситуація, коли кількість заброньованих місць перевищує реальну наявність номерів.
- **Номерний фонд** — Сукупність усіх номерів готелю, доступних для тимчасового проживання.
